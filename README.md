# Valeria Escobar, portfolio

Personal portfolio website, built with plain HTML, CSS and a little JavaScript. No tracking, no cookies and no third-party requests.

- `index.html`, `styles.css` and `script.js` are the page.
- `images/` holds the project images. The illustration in the Sustainable Transformations project is by Tiina R. The world map in the AI research agent project was generated with AI.
- `fonts/` holds Roboto and Inter, each with its own licence.
